## Implemented carry-over

The Rust suitability endpoint adds the read-only inspection path already present in the native product. It reports manual reservation capacity and current pressure through the same reservation owner as actual loads. It preserves Disabled intent and unknown physical fit. It does not infer context, complete companions, immutable identity, measured memory or qualified hardware support.

The crosswalk marks this infrastructure partial. It does not describe the native product's richer resource projection as fully ported. All previously planned core features remain open until their own Rust and real-engine acceptance passes.

## Review risks and next batch

R1 should first establish immutable artifact/profile/options identity, managed-directory ownership, consistent-generation restore and request principal/epoch/session context. Those owners are prerequisites for qualified suitability, persistent cache, acquisition, richer routing and safe assistant dispatch. Extending the experimental config independently for each feature would create duplicate identity and authority rules.

Keep the main worker's final contracts as inputs to that batch. Do not merge its uncommitted C++ mechanisms wholesale or claim its native acceptance as evidence for Rust.
