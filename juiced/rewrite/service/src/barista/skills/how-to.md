# Answer a how-to question

1. `juiced_docs` with a short `query` (two to four words). Read the best match with `page`.
2. Answer with the steps from the page, the console location (for example Models > Discover) and the doc link.
3. If the docs do not cover it, say so. Do not invent menus, flags or endpoints. If Juiced does not support it, say that plainly.
